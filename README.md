## Reflection Questions
### Which textures did you choose and why?
I chose a wooden barrel texture for the crates and gate because of both the natural wooden texture of it and the addition of the metal bolts which works well to add details that matches with both. I chose a stone brick for the castle walls, since they looked similar to what I saw in reference pictures, and a more textured rough stone brick for the ground. Finally, I chose a fabric texture with an interesting but subtle pattern on it to create the banners so they didn't look completely plain.
### How did normal maps improve your scene?
The normal maps helped a lot to add texture to the scene. While the color maps alone pasted the images on, they still looked completely flat. The normal maps added depth to make the textures look more realistic.
### Which object benefited the most from texture mapping?
I personally think that the ground looks the best after texture mapping. The rough stones do well with creating a sense of depth and realism. 
### What effect did roughness maps have on lighting?
Frankly, I think that there might be something wrong with my roughness maps because I didn't notice any differences when the roughness maps were added. However I was unable to find any obvious mistakes. In theory, the roughness maps should change which parts of the texture reflect more or less light.
### Did texture tiling improve or hurt realism?
Texture tiling improved realism, since without it the scale of the objects seemed very odd. Having only 4 stone bricks making up a castle wall doesn't make sense, so tiling helped put the correct scale on it.  
### If you had more time, what additional textures would you add?
If I had more time I would fix the roughness maps, improve the fabric texture so it looks less flat, and maybe add a grass texture outside of the courtyard and/or a different wood texture for the gate.
